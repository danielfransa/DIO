# Índice das explicações por arquivo

Esta pasta contém uma explicação individual dos principais arquivos do projeto. A ideia é permitir estudar cada peça separadamente e depois relacionar tudo com a arquitetura geral descrita em `aula-projeto-jogo-da-velha.md`.

## Headers

- [explain_ai_h.md](explain_ai_h.md): interface pública da inteligência artificial.
- [explain_game_h.md](explain_game_h.md): tipos e contratos das regras do jogo.
- [explain_input_h.md](explain_input_h.md): abstração das teclas e da entrada do terminal.
- [explain_render_h.md](explain_render_h.md): contrato de renderização da tela.

## Fontes C

- [explain_ai_c.md](explain_ai_c.md): implementação da IA e ciclo de dificuldade.
- [explain_game_c.md](explain_game_c.md): implementação das regras do jogo da velha.
- [explain_input_c.md](explain_input_c.md): configuração do terminal e leitura de teclas.
- [explain_main_c.md](explain_main_c.md): fluxo principal da aplicação.
- [explain_render_c.md](explain_render_c.md): desenho do jogo no terminal.

## Build

- [explain_makefile.md](explain_makefile.md): compilação, linkagem, execução e limpeza.
